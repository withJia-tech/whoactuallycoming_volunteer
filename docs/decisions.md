# Human decisions — all pending

Complete this checklist in the existing restricted project record. This repository records **proposals**, not approvals. The workbook has editable `thresholds_approved`, `operations_approved`, `approved_by`, `approved_on` and `protocol_version` fields. These are attestations, not authentication or an enforceable approval system. Do not set them to yes solely because synthetic tests pass.

The operational approval attests that every applicable row is resolved and the evidence/owners are recorded privately. The threshold approval attests the numeric values and all new scoring conventions. Approval must precede the send date in this date-only kit. Keep a named Sheet version and decision record; the offline checker cannot verify whether a human truly approved something or whether a provider delivered a message.

If a pending decision makes the current proposal unsuitable, revise the protocol before event 1. State the reason and the next evidence needed. Do not pre-commit to a database, matcher, new app, AI inference or a particular integration.
